# About This Project

This website provide simple way how to share family cooking recipes in free and available form.

## Why Use GitHub Pages?

1. **Free hosting** - No cost for personal sites
2. **Automatic deployment** - Push changes, site updates automatically
3. **No technical skills needed** - Just write in plain text using `.md` (markdown) syntax
4. **Secure** - Hosted on GitHub's infrastructure
